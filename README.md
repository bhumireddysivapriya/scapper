# Book Scraper Assignment

A beginner-friendly web scraper and REST API that collects public book data from [Books to Scrape](https://books.toscrape.com/), a website made for scraping practice. It stores results in SQLite and lets users browse, search, and filter the collected books.

## Features

- Scrapes book titles, prices, availability, ratings, and product links.
- Follows the practice site's pagination until it reaches the requested limit (up to 50 books).
- Saves books in SQLite and avoids duplicates using each product URL.
- Provides a FastAPI homepage and interactive API documentation.
- Includes a responsive dashboard with book statistics, title search, price filters, and product links.
- Supports title search and minimum/maximum price filters.

## Run locally

Requires Python 3.11 or newer.

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

### macOS/Linux

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) for the homepage or [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) for Swagger UI. The SQLite database (`books.db`) is created automatically in the current working directory.

## How the project works

The application has four main steps:

1. **Scrape:** `app/scraper.py` requests the catalogue pages from Books to Scrape. BeautifulSoup finds each book card and extracts its title, GBP price, availability, rating, and product URL. A missing title, price, or URL makes that card invalid and it is skipped; missing availability or rating is shown as `Unknown`.
2. **Store:** `app/models.py` describes the `books` table. SQLAlchemy in `app/database.py` creates and connects to the local `books.db` SQLite file. The product URL is unique so the same book cannot be stored twice.
3. **Serve the API:** `app/main.py` provides routes for the dashboard, scraping, and reading/searching saved books. The API returns JSON for book records and scraping results.
4. **Display:** the homepage uses browser JavaScript to request `/books`, then renders the returned records in the dashboard. Filtering asks the API for matching records; scraping calls `/scrape` and reloads the table when it finishes.

### Dashboard guide

- **Matching books** is the number of books currently returned by the filters.
- **Average price** is the mean GBP price of those matching books.
- **In stock** counts matching books whose availability says “In stock”.
- **Search title** finds titles containing the text entered, without case sensitivity.
- **Minimum price** and **Maximum price** filter by an inclusive price range. Either field can be left blank.
- **Apply filters** reloads the table with the selected search and price values. **Clear** removes all filters.
- **Scrape latest books** requests up to 20 books from the practice website. Existing product URLs are not saved again, and the dashboard reloads after scraping.
- The table shows each saved book's ID, title, price, availability, rating, and a link to its page on the practice site. On narrow screens, the table can be scrolled horizontally.

### Swagger UI (`/docs`) guide

Swagger UI is an interactive page generated by FastAPI from the API routes. Expand an operation to see its purpose and parameters. Select **Try it out**, fill in any values, and choose **Execute** to send the request and view its status and response.

| Route | What it does | Parameters |
|---|---|---|
| `GET /` | Returns the dashboard HTML page. | None |
| `POST /scrape` | Fetches books from the source site and saves new records. | `limit`: number of books to scrape; defaults to `20`, minimum `1`, maximum `50`. |
| `GET /books` | Returns saved book records as JSON. | `search`: optional title text; `min_price` and `max_price`: optional inclusive GBP bounds. |

For example, `GET /books?search=light&min_price=10&max_price=60` returns books whose title contains “light” and whose price is between £10 and £60. An invalid parameter (for example, `limit=0`) returns HTTP `422` with validation details. If the source site cannot be reached while scraping, the API returns HTTP `502`.

## API endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Book dashboard with statistics, filters, and a table of saved books |
| `POST` | `/scrape?limit=20` | Scrapes up to 20 books and saves new records; `limit` can be 1–50 |
| `GET` | `/books` | Lists all saved books |
| `GET` | `/books?search=light` | Searches book titles, case-insensitively |
| `GET` | `/books?min_price=10&max_price=50` | Filters books by an inclusive price range |

### Test each endpoint locally

In Swagger UI, expand each route and select **Try it out**. Or use a terminal:

```bash
curl http://127.0.0.1:8000/
curl -X POST "http://127.0.0.1:8000/scrape?limit=20"
curl http://127.0.0.1:8000/books
curl "http://127.0.0.1:8000/books?search=light"
curl "http://127.0.0.1:8000/books?min_price=10&max_price=50"
```

The scrape route returns the number of books scraped and how many new records were saved. Repeating the request does not create duplicate URLs. If the source website cannot be reached, the route responds with HTTP 502.

## Deploy on Render

1. Push the project to GitHub.
2. In Render, choose **New → Web Service** and connect the repository.
3. Configure the service:

| Setting | Value |
|---|---|
| Runtime | Python 3 |
| Build command | `pip install -r requirements.txt` |
| Start command | `uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| Instance type | Free |

4. Deploy, then open `https://<your-service-name>.onrender.com/docs` and test the API routes.

**Storage note:** SQLite is stored in the service's local filesystem. Free Render services use ephemeral filesystems, so the database may be reset when the service restarts or redeploys. This is suitable for a free assignment demo; use persistent storage if records must survive restarts.

## Limitations and future improvements

- Data is refreshed only when someone calls `POST /scrape`.
- The free deployment's SQLite file is not durable across service restarts.
- Possible improvements include scheduled scraping, pagination on the API results, and a dedicated persistent database.
